# Permutive iOS SDK Swift Package

This repo provides SPM support for Permutive iOS and Catalyst SDK.

You can find tvOS support [here](https://github.com/permutive-engineering/permutive-tvos-spm).

Please refer to the SDK documentation [here](https://docs.permutive.com/sdks/mobile/ios/overview).
Get the latest release notes [here](https://docs.permutive.com/sdks/mobile/ios/release-notes/index).

# Use Cocoapods?

Easily include Permutive SDK in your Podfile:

```
target 'Your Target' do
    platform :ios, '13.0'
    pod 'Permutive_iOS', '~> 3.0.0'
end
```
